Three costs on every query

01 — Discovery cost

Agents re-probe what data exists, what fields mean, and how sources relate — on every query, even when nothing changed.

02 — Interpretation failures

Without business context, agents guess. Does arr mean annual recurring revenue or array length? Wrong inference, wrong answer.

03 — Knowledge silos

What one agent learns never improves another. Quality doesn't compound, costs don't fall.

Precompute the durable.
Keep the volatile live.
Don't make your agent wander the whole library — hand it the card catalog.

The design principle

Schema definitions, field meanings, index routing — these are stable. Compute them once.

Live data stays live — agents query sources directly using the patterns KIs provide.

Build context once, reuse on every query. Quality compounds as KIs improve.

The Context Engine

A continuously optimizing knowledge layer between your data and any agent. Sources feed Automations that extract Knowledge Indicators into an AI Index. Agents retrieve KIs instead of probing raw data.

Key Terms

You'll see these throughout the labs.

AI IndexAn Elasticsearch index (named ai-index-idx-*) that stores pre-computed Knowledge Indicators. Created via the Context Engine UI.
KIKnowledge Indicator — a document in the AI Index containing pre-computed context: routing profiles, per-document summaries, or atomic facts.
Suggest AutomationThe built-in Context Engine feature that uses an AI agent to analyze your source and generate a KI automation automatically.
ES|QLElasticsearch's pipe-based query language. Agents use it to retrieve KIs and search source data. Supports FORK + FUSE for hybrid retrieval.
Agent SkillA portable SKILL.md file — instructions plus allowed-tools list — any compatible agent harness can load.
