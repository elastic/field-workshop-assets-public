Add your own test case.

Write a question and the ES|QL that answers it. Both agents run, and the judge grades them against your query.

This is the eval loop you will use in Lab 4, and it is the same loop you would run on your own agents.

  • Questions: a fixed set, and each one has a right answer written as ES|QL. That query is the ground truth.
  • Runs: both agents answer every question several times. LLM calls and tokens come straight from the run's usage report.
  • Score: deterministic checks first (did the answer name the right accounts, categories, articles?), then an LLM judge called through Elasticsearch's inference API, which reads the ground truth. An answer is correct only if both agree.
  • Store: one document per run in an Elasticsearch index.
  • See: a Kibana dashboard, plus Discover to read any single answer.

We recorded 50 runs ahead of time so a room full of people does not repeat the same LLM calls. Your own runs are scored live on top of them, and you can add your own test case.
