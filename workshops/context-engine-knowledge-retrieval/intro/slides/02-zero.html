This is a real run from this workshop: a baseline Agent Builder agent with the default tools and no Context Engine.

It has tools but no map of the data. So it plans, guesses an ES|QL query, runs it, and tries again. 21 LLM calls for one question.

The bigger problem is variance: the same agent, same question, took anywhere from 7 to 22 LLM calls across runs. Unpredictable cost and latency is what keeps agents out of production.
