The Context Engine · How KIs help

A KI answers, or it points the way. Ours point the way.

Some context is the answer. Some context is the map to the answer. This workshop uses routing KIs: the map.

Answers directly

The KI is the answer.

Question→KI→Answer

Good for durable findings, for example "what does our knowledge base say about login issues?"

Points the way · this workshop

The KI routes to live data.

Question→Routing KI→Right index, right fields→ES|QL on live data→Answer

The KI holds the map, not the rows, so answers stay current as the data changes.

Also: an AI Index can be fed from several ES|QL sources, and from external Connectors (Salesforce, ServiceNow, Zendesk, Jira, Confluence, SharePoint) in technical preview. Not covered in this workshop.

Two ways a KI earns its keep.

Answers directly: the KI contains a finding that is stable enough to reuse as is.

Points the way: the KI tells the agent which index to use, which fields matter, and how to join. The agent then runs one precise ES|QL query against live data. This is what you build today, and it is why answers stay fresh.

Footnote: AI Indices can also be fed by external connectors, in technical preview. We do not demo that here.
