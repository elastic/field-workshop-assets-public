Remember "arr"? This KI settles it, and names the join key, before the agent writes a single query.

The official definition: a KI is a document of reusable context, derived from raw data, that agents retrieve instead of rediscovering.

The docs list four kinds of content a KI can hold: business meaning, derived findings, source limitations, and verified query patterns.

On the right is a real KI from this workshop, lightly trimmed. It tells the agent what the index is for, what the fields mean, that arr is revenue and not an array, and how this index joins to support tickets.
