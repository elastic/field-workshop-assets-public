The official definition, straight from the docs. The key phrase is upfront investment: do the interpretation work once, not on every question.

Four building blocks:

  • Sources: the raw data, Elasticsearch indices today.
  • Automation: an Elastic Workflow that reads sources and writes Knowledge Indicators.
  • AI Index: an Elasticsearch index holding those KIs.
  • Agent: retrieves KIs at query time.

Everything left of the dashed line happens before anyone asks a question. Context Engine is Experimental on Elastic Cloud Serverless.
