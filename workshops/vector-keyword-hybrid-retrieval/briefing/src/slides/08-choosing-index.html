Choosing your vector index

Flat
Exact · brute force
Algorithm
Pre-filter, then score every remaining vector. Exact top-k.
Strengths
Exact: no approximation
Pre-filters shrink the set before any scoring
Limitations
Scores every vector it keeps, so cost grows with the data
Best for: small datasets · pre‑filtered subsets
Quantized HNSW
In-memory · approximate
Algorithm
Walk a proximity graph toward the query; rescore the candidates.
Strengths
Trades a little accuracy for a lot of speed
BBQ shrinks vectors ~32×; oversample 3× and rescore
The pick for 99%+ recall
Limitations
Only efficient when most vector data is held in memory
Best for: 99%+ recall · vectors that fit in RAM
GA 9.2 · Enterprise
DiskBBQ
Disk-based · approximate
Algorithm
k-means clusters. Find the nearest centroids; compare only their vectors.
Strengths
Vectors stay on disk, not in RAM
Degrades gracefully when RAM runs short
Default dense_vector in 9.4+ (where licensed)
Limitations
Good to about 95% recall; use bbq_hnsw above that
Best for: RAM-constrained · ~95% recall is enough
