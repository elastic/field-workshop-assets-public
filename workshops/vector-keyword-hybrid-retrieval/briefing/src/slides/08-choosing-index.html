Choosing your vector index.

FlatExact · brute force

Pre-filter, then score every remaining vector. Exact top-k.

  • No approximation
  • Filters shrink the set first
  • Cost grows with the data
Best forSmall datasets, pre-filtered subsets
Quantized HNSWIn memory · approximate

Walk a proximity graph toward the query; rescore the candidates.

  • A little accuracy for a lot of speed
  • The pick for 99%+ recall
  • Efficient only when most vector data is in memory
Best for99%+ recall, vectors that fit in RAM
DiskBBQOn disk · approximate

k-means clusters. Find the nearest centroids; compare only their vectors.

  • Vectors stay on disk, not in RAM
  • Degrades gracefully when RAM is short
  • Good to ~95% recall; bbq_hnsw above that
Best forRAM-constrained, ~95% recall is enough
