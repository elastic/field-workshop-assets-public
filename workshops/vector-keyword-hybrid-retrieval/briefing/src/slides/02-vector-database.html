Vector search basics · The big idea

Elasticsearch is a vector database.

01

Lexical + vector in one engine

Keyword and vector search share one index, so a single query can use both.

02

Embeddings run in-cluster

EIS, the Elastic Inference Service, hosts the model. No separate model server to stand up.

03

Scales past RAM

BBQ compresses vectors. DiskBBQ keeps them on disk when memory runs short.

Today you’ll use all three, without configuring any of it.
